# Chandan / Tram Kim Phu reference profile

## Sources

- VNG (2007): https://phongthan.vinagame.com.vn/tin-tuc/can-biet/truyen-thuyet-xoay-quanh-trang-bi-chan-dan.html — Chandan has six effects; 3 pieces enable the first three, full set enables all six. This article does not specify numeric values.
- Secondary corroboration: https://fsthoidai.com/1695632030-Thuoc_tinh_trang_bi_luc_Giap_Si.html — Chandan armor tooltip lists 20 all attributes, 20% base damage, 60 defense, 20% all resistance, 30 recovery, 20% weapon speed.
- Independent secondary image: https://phongvuong.adnxgames.vn/photos/1/chandangiap.png — same six values and order. This is ADNX, not proof of a particular VNG release's numeric values.
- https://fsthoidai.com/1695632123-Thuoc_tinh_vu_khi_hoang_kim_Giap_Si.html — level-100 Tram Kim Phu image shows five blue properties, no set requirement. Screenshot is upgraded/maxed, not a replacement for the local PAK min/max ranges.

## Reference only — per-set implementation withdrawn

The temporary per-record profile was removed before deployment at the user's request. These images are comparison evidence, not a source-level rules table. A shared data-driven loader must establish membership, effect IDs, values and thresholds from configuration.

Crafting GroupID must not be treated as SetID without a verified relationship. The current runtime does not attach those crafting rows to sets.

Tram Kim Phu's empty SetID demonstrates that SetID alone is not a universal quality/blue-property classifier. This remains part of the general schema audit.

Numeric set values are corroborated secondary-source values; this does not certify all VNG versions or all equipment. Native rule tests/builds are not in-game acceptance.
